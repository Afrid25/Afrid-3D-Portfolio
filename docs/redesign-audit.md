# Portfolio audit

Baseline 2840425 identifies the React 19, Vite 7, Tailwind 3 JavaScript portfolio. The canonical domain matches the owner profile. Direct live inspection was unavailable. Seven anchor destinations, a mobile menu, downloadable PDF, certificate viewer, EmailJS contact form, download grid and portfolio assistant are preservation targets. Projects come from src/constants. The homepage foregrounds a decorative portrait and student status while hiding project and resume actions. One project links to the owner profile as its source. Vercel handles hosting and API routes.
